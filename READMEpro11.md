# pro11anal2 — 통계 기초·가설검정·ANOVA·설문 분석

> **학습 목표:** 데이터의 변동성을 설명하고 목적에 맞는 가설검정을 선택해 근거 중심으로 해석한다.

## 1. 기술통계·추론통계

- **모집단/표본:** 전체 관심 집단과 실제로 관측한 일부 데이터.
- **평균·중앙값·최빈값:** 데이터의 대표값. **분산·표준편차:** 흩어진 정도.
- **표준오차:** 반복 추출되는 통계량(예: 표본평균)의 변동성.
- **추론통계:** 표본으로 모집단에 대한 가설을 검정하거나 모수를 추정한다.
- **귀무가설(H₀):** 일반적으로 차이/관계가 없다는 기본 가설.
- **대립가설(H₁):** 차이나 관계가 있다는 가설.
- **유의수준(α):** 실제로 H₀가 참인데 잘못 기각하는 제1종 오류를 허용하는 기준(예: 0.05).
- **p-value:** H₀가 참이라고 가정했을 때 관측한 통계량만큼 또는 그보다 극단적인 결과를 얻을 확률. **H₀가 참일 확률이 아니다.**

### 기본 해석

```text
p < α    → 귀무가설 기각 (통계적으로 유의한 결과)
p ≥ α    → 귀무가설 기각하지 못함 (차이가 없다고 증명한 것은 아님)
```

## 2. 검정별 필수 개념

| 목적/자료 | 대표 검정 | 주요 확인 사항 |
|---|---|---|
| 하나의 범주형 변수 빈도와 기대분포 비교 | 카이제곱 적합도 검정 | 기대빈도, 독립 표본 |
| 두 범주형 변수의 관련성 | 카이제곱 독립성 검정 | 교차표, 기대빈도, 독립 관측 |
| 한 집단 평균 vs 기준값 | 일표본 t-검정 | 독립 관측, 평균의 표본분포/정규성 |
| 서로 다른 두 집단 평균 | 독립표본 t-검정 / Welch t-검정 | 집단 독립, 정규성, 등분산성 여부 |
| 같은 대상의 전후 평균 | 대응표본 t-검정 | 짝지은 차이값의 분포 |
| 세 집단 이상 평균 | 일원분산분석(ANOVA) | 독립성, 잔차 정규성, 분산 구조 |
| 두 요인 및 상호작용 | 이원분산분석 | 주효과, 교호작용 |

### ① 카이제곱 검정
- 적합도 검정: 실제 범주별 빈도가 기대비율과 일치하는지 확인한다.
- 독립성 검정: 범주형 변수 간 관계가 있는지 확인한다.
- `pd.crosstab()`으로 교차표를 만든 뒤 `scipy.stats.chi2_contingency()`를 적용한다.
- 기대빈도가 너무 작으면 근사 기반 p-value가 불안정할 수 있어 대안 검정을 고려한다.

```python
import pandas as pd
from scipy.stats import chi2_contingency
obs = pd.DataFrame([[20, 10], [12, 18]])
chi2, p, dof, expected = chi2_contingency(obs)
print('p-value:', p)
```

### ② t-검정과 가정 진단
- `ttest_1samp()`은 한 집단의 평균이 특정 값과 다른지 검정한다.
- `ttest_ind()`는 독립 두 집단의 평균 비교에 사용하고, 분산 동질성이 의심되면 `equal_var=False`인 Welch 검정을 고려한다.
- `ttest_rel()`는 대응 표본(전후 측정)의 **차이**를 검정한다.
- `shapiro()`는 정규성, `levene()`는 분산 동질성 점검에 활용할 수 있으나 검사 결과만 기계적으로 따르지 않고 표본 크기·그래프도 함께 본다.

### ③ ANOVA와 사후검정
- **일원 ANOVA:** 집단 평균 중 적어도 하나가 다른지 확인한다. 유의한 결과만으로 어떤 두 집단이 다른지 확정할 수 없다.
- **사후검정(Tukey 등):** 집단 간 차이가 구체적으로 어디에 있는지 다중비교를 수행한다.
- **Welch ANOVA:** 분산이 서로 다른 경우 대안.
- **이원 ANOVA:** 두 요인의 주효과와 **상호작용(한 요인의 효과가 다른 요인의 수준에 따라 달라짐)**을 구분한다.
